# QuizCraft Audio Assets Directory

You can place optional custom audio files here:

- `background.mp3` - Background jungle/adventure music track
- `correct.mp3` - Cheerful sound played on correct answers
- `wrong.mp3` - Soft friendly error sound on wrong answers
- `timer.mp3` - Alert sound when timer has <= 5 seconds left
- `complete.mp3` - Victory fanfare celebration sound on quiz completion

> **Note:** If these `.mp3` files are not provided, QuizCraft automatically uses the built-in Web Audio API synthesizer to generate rich procedural sounds and jungle adventure music in real-time, with zero dependencies!
